## Context

This portfolio project needs independent, private version history and safe example data.

## Decision

Use a local-only Git repository and synthetic or public data only.

## Why

This follows the project-hub Git policy while allowing the dashboard to demonstrate realistic workflows without exposing client information.

## Consequences

No remote will be added. Any future data must be labeled with its synthetic or public source status.
